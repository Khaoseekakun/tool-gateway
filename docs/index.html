The pipeline (high level)

sequenceDiagram
    participant U as Your app
    participant G as ToolGateway
    participant M as Model (OpenAI / Claude / Gemini / Cohere)
    participant T as Your tool code

    U->>G: createToolGateway() + register()
    U->>G: toTools(gateway, provider)
    U->>M: chat request with provider-formatted tools
    M-->>U: tool_calls (provider wire format)
    U->>G: runToolCalls(gateway, toolCalls)
    Note over G: auto-detect provider
middleware (onion)
JSON-Schema validation
timeout guard
    G->>T: execute(input)
    T-->>G: output
    G-->>U: results in provider's native format
    U->>M: append results → model continues
